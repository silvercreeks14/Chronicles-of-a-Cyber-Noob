# PHP2Shell: Critical PHP Vulnerabilities (CVE-2026-109618 & CVE-2026-109619)
**Date of news:** 2026-10-20

- **What happened:** The PHP project just released emergency patches for "PHP2Shell," two critical vulnerabilities that allow attackers to remotely execute code and take full control of web servers without needing a password. 
- **Why it caught my attention:** PHP powers nearly 70% of the internet, so the blast radius is massive. What's crazier is that attackers began attempting to exploit this four days *before* the vulnerabilities were publicly disclosed. Some government agencies even took their websites entirely offline as a precaution.
- **The Takeaway:** The window between a vulnerability being discovered and it being actively exploited is shrinking to zero. Defense-in-depth and rapid incident response (like temporary Web Application Firewall mitigations) are mandatory because you can no longer just wait for the official patch to drop.
