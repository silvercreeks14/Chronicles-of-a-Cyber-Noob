# Chronicles of a Cyber Noob 🛡️

Welcome to my threat intelligence and cybersecurity learning journal. 

This repository serves as a public portfolio documenting my evolution in the cybersecurity field. Every two weeks, I analyze current threats, dissect new technologies, and document my bootcamp progress by mapping real-world scenarios to industry frameworks like MITRE ATT&CK.

## 🗂️ Repository Structure

*   **`/Threat-Analyses`**: Deep dives into current malware, ransomware variants, and APT campaigns.
*   **`/Concept-Summaries`**: Technical breakdowns of core cybersecurity concepts, protocols, and architectures.
*   **`/Bootcamp-Challenges`**: Walkthroughs, CTF write-ups, and practical applications from my ongoing training.

## 🎯 The Mission
To maintain a disciplined routine of converting raw information—from industry podcasts, global tech news, and hands-on labs—into structured, actionable intelligence. 

*"The only difference between a noob and an expert is a well-documented trail of mistakes and lessons."*
